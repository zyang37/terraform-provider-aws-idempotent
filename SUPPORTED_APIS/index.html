    Supported AWS APIs (idempotency-token operations)#

    Generated by tools/gen-idempotent-ops/gen.py from the Smithy models in aws/aws-sdk-go-v2/codegen/sdk-codegen/aws-models. Do not edit by hand.

    Sources: aws-sdk-go-v2 commit 4e0240a, terraform-provider-aws v6.64.0, generated 2026-09-15.

    • Tier 1 (trait smithy.api#idempotencyToken): 1439 operations across 195 services. aws-sdk-go-v2 auto-fills these with a random UUID if left empty; our middleware sets a deterministic token first, so the SDK leaves it alone.
    • Tier 2 (token-named member, no trait): 170 operations. The SDK does not touch these; the provider must set them explicitly.
    • Called by upstream terraform-provider-aws today: 519 Tier 1 and 57 Tier 2 operations. These are the operations where the idempotent provider changes real apply behavior.
